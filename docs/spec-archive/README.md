# Spec archive — historical drafting artifacts

`part1.md`–`part11.md` are the original eleven drafting documents for the Ledger
specification. On 2026-07-21 they were merged into a single canonical
`LEDGER_MASTER_SPECIFICATION.md` v1.0 (at the repo root), with duplication removed
and contradictions resolved per the decisions in `LEDGER_CONSTITUTION.md` §13.

These files are **superseded** and retained only as historical record. Do not
edit them and do not treat them as canonical — the merged master specification is
authoritative. Mapping:
