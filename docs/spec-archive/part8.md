# Chapter 78 — Screen Philosophy

Every screen exists to answer one primary question.

A screen should never compete with itself.

A user should immediately understand:

• Why am I here?
• What is the most important information?
• What should I do next?

Every screen follows the same hierarchy.

────────────────────────────

1.
Primary Question

2.
Primary Answer

3.
Supporting Context

4.
Suggested Action

5.
Supporting Evidence

────────────────────────────

If this hierarchy is violated,
the screen should be redesigned.

Every screen supports accessibility.
